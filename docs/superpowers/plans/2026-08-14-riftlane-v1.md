# RIFTLANE v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a locally playable browser FPS — linear CTF with random loadouts (Husky Raid style), authoritative Node multiplayer, smart bots, Three.js client, all-procedural original assets.

**Architecture:** npm-workspaces monorepo with a dependency-free `shared/` package (deterministic sim: movement, combat, flags, maps) consumed by both an authoritative `server/` (30 Hz sim, WebSocket, rooms/queue, bots) and a `client/` (Vite + Three.js, client-side prediction, snapshot interpolation, HTML HUD).

**Tech Stack:** TypeScript, Node ≥ 20, `ws`, Three.js, Vite, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-14-riftlane-design.md`

## Global Constraints

- `shared/` imports NOTHING (no Node, no DOM, no npm deps). Pure TS.
- All game constants live in `shared/src/constants.ts` — never inline magic numbers in server or client.
- Original IP only: names/models/sounds from the spec (RIFTLANE, Pulse SMG, Triad Rifle, Railspike, Boomtube, Scattergun, Sidearm, Swarm Pod, Ion Charger, Arc Blade, Grav Maul). Never write "Halo", "Spartan", "Needler", etc. in code, UI, or assets.
- Zero downloaded assets. Geometry is code-built; audio is WebAudio-synthesized.
- Server tick 30 Hz; snapshots 20 Hz; JSON protocol (binary is out of scope).
- No accounts, no database, no deployment. Local only.
- Windows dev box: scripts must run under PowerShell and Git Bash (use `npm run`, no shell-specific syntax in package.json scripts).
- Tests: Vitest. Every shared/server task is TDD. Client render tasks verify by running the app and seeing it.
- Commits after every task (`git init` in Task 1). Conventional-commit style messages.
